# FPGA VPK180: Getting Started

This README provides an introduction to the Versal Premium device and step-by-step instructions for setting up, debugging, and programming the VPK180 FPGA board. It assumes that you have already generated the bitstream and installed the necessary tools. Please refer to the following guide before proceeding:

* [Bitstream Generation Guide](./RunOnFPGA.md)

## Design Flow

The VPK180 target only supports a design flow with Processing System (PS) connections. Similar to Processing System-enabled designs on other FPGA targets, in this flow, X-HEEP is connected to the **Processing System (PS)** via JTAG, UART, and some of the GPIO pins.

![Figure 1: VPK180 on-chip PL-PS connections.](./../images/VPK180-flow.drawio.png)

Figure 1 shows the connections between X-HEEP and the PS. This implementation enables the APU to properly program applications on X-HEEP. Using JTAG, the APU can program the ELF file into the embedded memory banks of the text section, select the boot mode, and retrieve the return value of the application using **GPIOs**. It can also optionally monitor the stdout of the code being executed via UART.

## Programming the Board

To program X-HEEP, follow these steps:

5. **Compile the App**

   Refer to the [Compile the Apps Documentation](./../How_to/CompileApps.md).

   ```bash
   make app TARGET=vpk180 PROJECT=hello_world
   ```

6. **Program via JTAG**

   Copy the generated `.elf` file to the Linux system running on the PS. Then, run the `xheepRun_vpk180.py` script to program the device:

   ```bash
   sudo python3 src/xheepRun_vpk180.py \
       -f path/to/elf_file.elf \
       --jtag-addr 0xA4000000 \
       --gpio-addr 0xA4020000 \
       --uart 0xA4010000
   ```

   The script must be run with `sudo` privileges to access the JTAG, GPIO, and UART modules.

   > [!WARNING]
   > Make sure to provide the correct physical addresses of the UART, JTAG, and GPIO modules. Otherwise, the script will not work and, in some cases, may cause a kernel panic.

7. **Optional: Open a Serial Connection for Debugging**

   To view `printf` output in the terminal, you can connect to the UART channel from the PS using the `uart_monitor.py` script. Run the following command:

   ```bash
   sudo python3 src/uart_monitor.py -t 100 -a 0xA4010000
   ```

   > [!NOTE]
   > Make sure to provide the correct physical address of the UART device.
